# Input

Job requests MUST include exactly 1 input representing the type of statistic desired. 

Supported values are: `trending`

# Output

Only allowed mime type:

* `application/json`

Which returns the payload as a stringified JSON array of 2 events of the token that is ranked highest or close to highest in the trending scale: one being the event that created it (1175) and the other being the definition for it (31175).

# Example

## Request to know the most trending token 

```json
 {
  "kind": 5177,
  "content": "",
  "tags": [
    [ "i", "trending", "text"], 
    [ "output", "application/json" ]
  ],
  ...
}
```

## Relay response

```json
 {
  "pubkey": "<relay pubkey>",
  "content": "[<a stringified 1175 event that created the token>, <a stringified 31175 event that is the token's definition]",
  "kind": 6177,
  "tags": [
    ["request", "<stringified 5177 job-request event>"],
    ["a", "<address of the definition 31175 event from content>"]
  ],
  ...
}
```
