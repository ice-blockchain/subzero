ICIP-7000
======

Rich Text Support
-----

`mandatory`

This ICIP adds rich text support for existing text events, I.E. 1, 14, 30023, 30024, 30175, etc.

Clients that want to display rich text to their users MUST add a `rich_text` tag to any of the relevant text events, I.E. 1, 14, 30023, 30024, 30175, etc., with the following format:
```json
["rich_text", <protocol>, <relevant rich text content>]
```
Supported protocols:
* `quill_delta` -- [Quill Delta](https://quilljs.com/docs/delta)

The supported protocol list is not binding in any way, clients can implement any protocol they choose and MUST also ignore any protocol they do not support.

Clients MUST still respect the content rules of the text event they publish, I.E. markdown for long form content (30023), text for simple notes (kind 1), because by doing so they maximise the compatibility with different client implementations that might not support rich text.

### Relay Considerations

Relays MUST not validate and not index the `rich_text` tag in any way.
