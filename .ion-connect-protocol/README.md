### ION Connect Protocol is an extension of [NOSTR Protocol](https://github.com/nostr-protocol/nips)

##### This folder aggregates all modifications made to the NOSTR Protocol as well as all the custom ICIPs (ION Connect Implementation Possibilities) exclusive to ION Connect Protocol.

###### Those modifications or additions are not **yet** supported by the NOSTR protocol.
