ICIP-9000
======

Fiat Payment Proof
-----------------------------------

`draft` `optional`

This ICIP adds support for proving an user payed for something, given a trusted entity is providing that proof.

The payment itself can theoretically be in anything, but for the current scope of this version of this ICIP, it will be limited to FIAT currency only. 

## Event structure

A new kind `1758` event is defined, that :

1. MUST be signed the trusted entity (which can never be the user itself)
2. MUST have an empty content
3. MUST have a `p` tag of the payer
4. MUST have a `r` tag with the absolute url to the payment itself
5. MUST have a `L` tag with 2 associated `l` tags with the information about the productId  

```json
{
  ...
  "kind": 1758,
  "content": "",
  "tags": [
    ["p", "<payer-masterPubkey/pubkey>"],
    ["r", "<absolute external url to the payment details>"],
    ["L", <productId label namespace>],
    ["l", "<absolute external url to the product id definition>", <productId label namespace>],
    ["l", <productId>, <productId label namespace>],
    ... any other relevant tags
  ]
}
```
