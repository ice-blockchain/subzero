# Input

Job requests MUST include exactly 1 input representing the type of statistic desired. 

Supported values are: `trending`

# Output

Only allowed mime type:

* `application/json`

Which returns the payload as a stringified JSON of the 31175 event that is ranked highest or close to highest in the trending scale.

# Example

## Request to know the most trending token 

```json
 {
  "kind": 5177,
  "content": "",
  "tags": [
    [ "i", "trending", "text"], 
    [ "output", "application/json" ]
  ],
  ...
}
```

## Relay response

```json
 {
  "pubkey": "<relay pubkey>",
  "content": "<a stringified 31175 event>",
  "kind": 6177,
  "tags": [
    ["request", "<stringified 5177 job-request event>"]
  ],
  ...
}
```
