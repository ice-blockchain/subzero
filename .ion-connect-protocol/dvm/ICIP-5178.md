# Input

Job requests MUST include exactly 1 input text with value `inspectTokenBuyingActivity`.

# Params

## `author`

Specifies the desired author (b tag of 31175) for whom you want to inspect the buying activity on their tokens.

```json
[ "param", "author", "695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919" ]
```

# Output

Only allowed mime type:

* `application/json`

Which returns the payload as a stringified JSON array of 2 events of the token that is showing a significant buying activity increase: one being the event that created it (1175) and the other being the definition for it (31175).

# Example

## Request to know if any tokens of the desired author are showing a significant buying activity increase

```json
 {
  "kind": 5178,
  "content": "",
  "tags": [
    [ "i", "inspectTokenBuyingActivity", "text"],
    [ "param", "author", "695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919" ],
    [ "output", "application/json" ]
  ],
  ...
}
```

## Relay response

```json
 {
  "pubkey": "<relay pubkey>",
  "content": "[<a stringified 1175 event that created the token>, <a stringified 31175 event that is the token's definition]",
  "kind": 6178,
  "tags": [
    ["request", "<stringified 5178 job-request event>"],
    ["buying-activity", "30", "24h"], // 30 is the number of users
    // the token that is showing a significant buying activity increase
    ["a", "31175:b535f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919:something"],
    ["p", "695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919"]
  ],
  ...
}
```
