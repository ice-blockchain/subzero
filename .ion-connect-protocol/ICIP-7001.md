ICIP-7001
======

Positional Markdown Override Support for Note Text
-----

`mandatory`

This ICIP adds support for replacing/overriding parts of the Note(kind 1)'s text content with snippets of Markdown text.

This is necessary to add more advanced styling and components to the Note's text, without braking the compatibility with other NOSTR clients/relays.


### Definition

We define a new `pmo` tag (short for positional markdown override) of the following structure:

```json
[
  "pmo", "<startIndex>:<endIndex>", "<markdown replacement>"
]
```

* startIndex - zero based index of the star character in the event's content where the replacement begins
* endIndex - zero based index of the end character in the event's content where the replacement begins 

**_Example:_**
```json
{
  "kind": 1,
  "content":"Breaking NEWS! Aliens have landed on the moon! Read all about it on https://bogus.blog.com!",
  "tags": [
    ["pmo", "15:21", "*Aliens*"],
    ["pmo", "68:89", "[Bogus Blog](https://bogus.blog.com)"],
    other tags...
  ],
  // other fields...
}
```
