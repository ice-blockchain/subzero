ICIP-2001
======

Affiliated Users
-----

`draft` `optional`

This ICIP extends ICIP-2000 with the possibility of having a many-to-many relationship between masters and delegates: a master can be affiliated with multiple "other" accounts (of other users or devices of that master user itself) and any account can be affiliated with multiple masters.

### Modifications

Kind 10100 now has a stringified JSON array in its content, where each element in that array represents the kind `1759` of a specific `p` tag affiliated with that master (the proof that the other user accepts to be affiliated with this user)

The kind `1759` event MUST be sent by both parties, the master's `1759` being the first one sent in the flow, and the other user's `1759` event being a response to the master's (because users cannot invite themselves to be affiliated with a master without the master's preliminary request)

Kind `10100`'s content MUST never contain `1759` events of the same master; ONLY other user's devices MUST be present in the content, NEVER the master's own devices.

### 1759 Event

The event has no content and 3 relevant tags:

1. `request`
   * mandatory for 2nd event; MUST be missing for first event
   * strigified JSON event of master's 1759
2. `p`
    * mandatory for both events
    * extended format only:
      ```json
       ["p", "<masterPubkey of the target(master or affiliate)>", "", "<devicePubkey of the target(master or affiliate)>"]
      ```
3. `expiration`
   * mandatory for first event; MUST be missing for the 2nd event
   * timestamp, no more than 24h in the future

#### Example:
```json
{
  ...
  "kind": 1759,
  "content": "",
  "tags": [
    ["request", "the master's stringified 1759 event"],
    ["p", "<masterPubkey of the target(master or affiliate)>", "", "<devicePubkey of the target(master or affiliate)>"],
    ["expiration", 1600000000],
    ...
  ]
}
```

### Client and Relays

Both Clients and Relays MUST validate the 1759 event strictly both on its own and also in conjunction with the `10100` event of the master.
