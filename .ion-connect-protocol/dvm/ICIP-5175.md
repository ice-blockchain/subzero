# Input

Job requests MUST include at most 1 input representing the prefix keyword they are searching for to get the most relevant hashtags (I.E. top-most used-) that start with that keyword.

If no input is specified the most relevant hashtags globally will be returned. 

The input, if present, supports only the `top` marker.

# Params

## `limit`

Specifies the desired limit/number of hashtags to be returned. Default is 10.

```json
[ "param", "limit", "10" ]
```

# Output

Only allowed mime type:

* `application/json`

Which returns the payload as a JSON string array, where each string is the hashtag itself. 

# Example

## Request top hashtags that start with #something

```json
 {
  "kind": 5175,
  "content": "",
  "tags": [
    [ "i", "#something", "text", "", "top"], --optional
    [ "param", "limit", "3"], --optional
    [ "output", "application/json" ]
  ],
  ...
}
```

## Relay response

```json
 {
  "pubkey": "<relay pubkey>",
  "content": "[\"#something1\",\"#something2\",\"#something3\"]",
  "kind": 6175,
  "tags": [
    ["request", "<stringified 5175 job-request event>"]
  ],
  ...
}
```
