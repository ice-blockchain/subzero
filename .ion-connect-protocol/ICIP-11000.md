ICIP-11000
=======

Tokenized Communities
-----

`draft` `optional`

This ICIP defines all the events and interactions between ION Connect Relays, ION Connect Clients and _-indirectly-_ the blockchain that manages the Community Tokens, which can be ION Blockchain or any other EVM based blockchain.

### Community Token Definition Event

Community Tokens are represented in the ION Connect ecosystem as "meta" events associated with some other specific events. For the purpose of this ICIP, the following kinds can have those "meta" events associated with them:
* Kind 0
* Kind 1 
  * only root content and non-time limited events _-events that have the `expiration` tag set-_
* Kind 30175 
  * only root content and non-time limited events _-events that have the `expiration` tag set-_

The Community Token Definition Event is a new kind `31175` event that has the following specifications:
* `content` is empty
* an `e`/`a` tag MUST be set, pointing to the event it is associated with
* the `b` tag and the keypair of the event MUST be the same ones as for the associated event
* a `k` tag MUST be set representing the kind of the associated event
* the `created_at` of both the meta and the associated events MUST be within a very small window (under 10s), preferably identical

This Community Token Definition Event can be used as a second, hidden root of the associated event so that comments or anything that can be linked to the associated event can also be liked to this new event, and that behaviour can be handled by clients however they see fit: they could have the 2 events(meta & associated) be independent roots, each having independent graph of relationships, or they could aggregate all relationships under one single root. Additionally, in the case of the kind 0 associated event, this meta event could behave as another type of post.

Thus, the Community Token Definition Event being considered a post, inherits all the other features of a post, I.E. it can be quoted, reposted, etc. If it is reposted, a kind 16 event with k:31175 event MUST be created. 

**_Example:_**
```json
{
  "kind": 31175,
  "content": "",
  "tags": [
    ["a", "0:a695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919:"],
    ["b", "a695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919"],
    ["k", "0"],
    other tags...
  ],
  // other fields...
}
```

### Community Token Action Notification Event

When a Community Token is interacted with in the blockchain (bought, sold, swapped, etc.) an event MUST be sent to both the owner of that token's relays but also to the relays of the doing the action itself (the buying, selling, etc.)

A new kind `1175` event is defined to notify the network about the user's action, with the following specifications:
* `content` is empty
* an `e`/`a` tag MUST be set, pointing to the event definition (31175)
* a `network` tag MUST be set, with the label/name of the blockchain itself
* a `bonding_curve_address` tag MUST be set, address of the bonding curve smart contract on the blockchain
* a `token_address` tag MUST be set, address of the community token on the blockchain
* a `tx_address` tag MUST be set, address of the specific transaction for that community token on the blockchain
* a `tx_type` tag MUST be set, the type of transaction for that community token on the blockchain, I.E. buy, sell, swap, etc
* a `tx_amount` tag MUST be set, the amount of tokens transacted, excluding gas and fees, with the currency of tokens transacted (I.E. ION, ETH etc) as the 2nd value of the tag; you can have multiple `tx_amount` tags

This new event can also be treated as a new type of post, inheriting all the properties of a post: being reposted, quoted, having comments, likes etc.

**_Example:_**
```json
{
  "kind": 1175,
  "content": "",
  "tags": [
    ["a", "31175:a695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919:something"],
    ["b", "a695f6b60119d9521934a691347d9f78e8770b56da16bb255ee286ddf9fda919"],
    ["network", "ethereum"],
    ["bonding_curve_address", "0xD76b5c2A23ef78368d8E34288B5b65D616B746aE"],
    ["token_address", "0xb302472D9526AE979F3134097C873d85E4a4502c"],
    ["tx_address", "0xae805fDC38dFf250b2597bC2b20ee9Bc2390D156"],
    ["tx_type", "buy"],
    ["tx_amount", "23630", "ION"],
    ["tx_amount", "653", "SOME_OTHER_TOKEN"],
    other tags...
  ],
  // other fields...
}
```
