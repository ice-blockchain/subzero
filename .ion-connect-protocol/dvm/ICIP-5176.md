# Input

Job requests MUST include exactly 1 input text with value `priceChange`.

# Params

## `token`

Specifies the `a` reference of the 31175 event you want to get the price change for.

## `timeWindow`

Specifies the desired time window the price change applies to. It is specified in seconds.

## `deltaPercentage`

Specifies the desired percentage of change. It can be negative or positive

```json
[ "param", "token", "31175:<someMasterKey>:<someDtag>"]
[ "param", "timeWindow", "300" ]
[ "param", "deltaPercentage", "10" ]
```

# Output

Only allowed mime type:

* `application/json`

Which returns the payload as a stringified JSON array of 2x 1175 events, one from $timeWindow time in the past, one from now. 

If the price didn't change in the specified timeWindow for the specified deltaPercentage, a `content:"[]"` is returned instead.

# Example

## Request to know if the price increased more than 10% in the last 5 minutes

```json
 {
  "kind": 5176,
  "content": "",
  "tags": [
    [ "i", "priceChange", "text"], 
    [ "param", "token", "31175:<someMasterKey>:<someDtag>"], 
    [ "param", "timeWindow", "300"],
    [ "param", "deltaPercentage", "10"],
    [ "output", "application/json" ]
  ],
  ...
}
```

## Relay response

```json
 {
  "pubkey": "<relay pubkey>",
  "content": "[<a stringified 1175 event from 10 minutes ago>, <another stringified 1175 event from now>]",
  "kind": 6176,
  "tags": [
    ["request", "<stringified 5176 job-request event>"],
    [ "a", "<address of the token both 1175 content events point to>"]
  ],
  ...
}
```
